# Welcome to the Pyth-MPG organization!

[![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.18672614-blue.svg)](https://doi.org/10.5281/zenodo.18672614)
[![readthedocs status](https://app.readthedocs.org/projects/pythmpg/badge/?version=dev)](https://pythmpg.readthedocs.io/en/dev/) 

The ``pythmpg`` package provides tools for enumerating symmetry
properties of all 122 magnetic point groups (MPGs), and for
counting the number of independent components of arbitrary-rank
tensors under those symmetries as classified by their Jahn symbol.

The python codes for analyzing the MPGs are provided in the
``pythmpg`` repository.  Using these, it is possible to construct
Excel spreadsheets containing the resulting information as
explained in the User Guide.  Example scripts are provided in
the ``examples/`` subdirectory of the repository along with
the resulting spreadsheets.  Users should be able to generate
their own spreadsheets following those examples with only a
limited knowledge of ``python.``  Those who are only interested
in making use of the sample spreadsheets can avoid ``python``
coding entirely and simply download them from that directory,
or from Zenodo at the link given below.
